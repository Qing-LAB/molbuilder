## 3. The end-to-end test — exactly where it is

**The system** (user: "a fake 3x3x6 Au – BDT – Au, fix all Au, only BDT
free, very loose so one step finishes, then transport from it").

* `projects/claude-vib-ui/structure/au333x6_bdt.xyz` + `.molstruct.json`
  — 120 atoms: 108 Au (two Au(111) 3×3×6 slabs), C6H4S2 (BDT with the thiol
  hydrogens removed). Built with the documented CLI pipeline:
  `molbuilder smiles "SC1=CC=C(S)C=C1"` → `modify --delete 8,11` →
  `modify --orient-axis 0,5 --center midpoint` →
  `modify --electrode Au:111:3x3x6@contact=2.4:registry=B:+z=5
  --electrode Au:111:3x3x6@contact=2.4:registry=A:-z=0`.
* Labels: `L-electrode` = atoms 66–92 (the three outermost layers at low
  z), `R-electrode` = 39–65, `bridge` = everything else (the inner three
  layers each side and the molecule, 66 atoms), `frozen_atoms` = all 108 Au.
  Written through the structure codec (`StructureCodec().write`), then the
  pair was loaded on the Molbuilder tab, its cell set on the **Cell page**
  (axis c, gap = one layer spacing 2.3545 Å, "span + gap" → c = 37.065 Å),
  and saved with the tab's own **Save to project**.
* Note: the builder used the experimental lattice constant (a = 4.078 Å,
  layer spacing 2.354 Å). PBE's is 4.158. Consistent within the ladder
  (leads and device come from the same file), slightly compressed gold.
  `molbuilder validate` warns only about the H/heavy ratio and a tight cell,
  both expected for a periodic metal junction.

**The description** — `projects/claude-vib-ui/optimization/au333bdt-loose/`:

* made through the UI: Structure optimization tab (loaded the pair with
  **Load from selection**, Auto-detect, form: `relax_steps 1`,
  `relax_force_tol 0.5`, `dm_tolerance 0.001`, `max_scf_iter 80`,
  `mesh_cutoff 150`, `kgrid 2 2 1`, DZP, PBE, 300 K, `system_label
  au333bdt`, `psml_lib pseudopotential`) → **Send to Task setup** (into the
  folder made with the sidebar's New folder) → Task setup: Hierarchical,

* prepared: `molbuilder jobset prep run coarse --bundle
  claude-vib-ui/optimization/au333bdt-loose --target this` → deck
  `01_coarse/run-0/au333bdt_01_coarse.fdf` (905 lines; `MD.Steps 1`,
  `MD.MaxForceTol 0.5 eV/Ang`, `MaxSCFIterations 80`, `DM.Tolerance 1e-03`,

  108 gold atoms, `LatticeVectors` c = 37.065). **Not launched.**
