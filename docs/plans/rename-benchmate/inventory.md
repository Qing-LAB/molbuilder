# Rename inventory — where the name "molbuilder" lives

**Role:** record (measured inventory for the rename plan)
**Domain:** all
**Measured:** 2026-10-18, at commit `83e72b2` (molbuilder 2.9.4)
**Owner of the plan:** [`README.md`](?doc=plans/rename-benchmate/README.md) in this folder

These numbers were counted, not estimated. Phase 0 of the plan re-runs the commands below at the commit where the rename actually starts.

for d in molbuilder tests docs scripts tools; do
