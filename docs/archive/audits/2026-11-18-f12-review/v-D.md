## CONFIRMED W / C

**D2 (W).** Some transport settings are written to the SIESTA deck at fixed precision: the bias point (`.4f`) and the four NEGF/TBtrans broadenings (`.6f`). The deck then computes something other than what the person set, what the run's record states, and what the folder is named for. A point of 0.00625 V runs at 0.0063 V. Two points, 5e-5 and 6e-5 V, run the same 0.0001 V in two folders. An eta of 5e-7 eV is written as 0, which the chapter says means no broadening. Who: anyone sweeping bias in steps finer than 0.1 mV, or setting a tiny eta. Smallest fix: write these items losslessly in `_FMT` (`g` / `repr`, as unformatted items are already written), keeping fixed formats only where `siesta.md` documents them (the SCF tolerances).

**D3 (W).** The Task setup stage table offers `job_name` as a stage column for a PySCF calculation, and prep accepts the override. In a PySCF ladder with `"overrides": {"job_name": "h2b"}` on one stage, that rung's deck says `JOB = "h2b"`, and every file it reads and writes is named from it. It looks for `h2b.chk` / `h2b_optimized.xyz` while the launch copied `<label>.chk` / `<label>_optimized.xyz`, so it starts cold despite `restart = continue`. It writes `h2b_NN_<stage>.log` etc., which molbuilder's readers (looking for the label's names) do not find. The next rung finds no `<label>.chk`. Smallest fix: make PySCF's identity field `shared` like SIESTA's. Mark `job_name` `shared` for the kinds PySCF runs, and let `IDENTITY_ITEMS` / `why_shared` cover it (or derive the identity from the engine table's `identity_field`). `why_not_in` then refuses it as an override and the stage table stops offering it.

**D6 (W, small).** For a charged molecule's SIESTA vibration, prep writes `makov_payne_correction.py` beside the fc phase's deck too. Run there, as the deck says, it prints the last FC step's energy as `E_total (raw)` and `E_total (corrected)`. That energy belongs to a displaced geometry, not the molecule's. The ΔE_MP term is right, and the totals are off by one displacement's energy (meV scale). Who: a person correcting an ion's energy from the fc folder. Smallest fix: write the script only beside decks whose last step is the result (not beside the fc phase's deck). Or have the script, when the output is an FC run, read the reference (undisplaced) step instead of `steps[-1]`.
