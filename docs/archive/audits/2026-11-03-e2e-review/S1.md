## 4. The pattern

The expectations themselves held: every number, word and record these tests compare still matches the chapters as they
read today, because each release since 2.57.0 that touched these roads swapped the test's words in step (2.58.0
take-over, 2.60.0 names, 2.62.1 *failed*/*short of done*). What drifted is everything a word swap does not reach: a
negative assertion whose target text left the code (the wall line, 2.54.1; `#ir-atoms`, 2.49.0) now passes vacuously;
docstrings keep reasons and row numbers the contract renumbered or replaced (§ 2.2's table, the sweep's group,
parity); and each release's *new* observable — the later stage's tolerance, a stopped walk's *not run*, the run's
`continued_from`, the run heading, the Fermi level's value — was listed "untested until after F9" and never added to
the runs the pass already makes. Older habits remain beside that: browser tests reach the folder through planted
sessionStorage, the relax gate tests are seven bodies of one table with the code's own formatting copied into their
expectations, and a few checks (prep's decks, a container's citation refusal, one-stage `summarize`) ride the e2e
though no engine is needed to show them.
