## 4. The pattern

These files drifted less by contract than by text and by side doors. Two assertions check the *absence* of strings the
code no longer writes (`Loading from schema`, `cell was checked`), so they went green-and-empty when the copy changed and
nobody noticed; a fixture prunes a workspace id the tab stopped using. The only edits since 2.57.0 were to follow the code's
words (`element(s)`→`species`) — expectations tracking UI copy rather than the contract's facts, which also produced the
"DFT — stated" pin against form-schema § 1.1. Meanwhile the releases that moved these roads (2.65.0's locks into the
catalogue and the hand-over library door, 2.57.0's species labels) added no browser row: each changelog marks its page
readings "untested before F9", and they are still unowned. Fixtures reach state by doors the person does not use —
a patched picker root instead of the one projects door, planted sessionStorage, a topic name the sidebar refuses, a
hand-written `task.json` — and several tests are separate functions where the contract has one rule with rows.
