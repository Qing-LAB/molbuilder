## 4. What drifted, and why

Nothing in this half of the file contradicts the contract as it reads today: each release since 2.57.0 edited its
expectations by hand to the new words (a point *short of done*, `every_run(calc, st)`, the data file's element), so the
assertions follow the code — but none of them has run since 2.56.2, and the edits only kept old rows alive; they added
no row for what each release introduced. The drift is therefore by omission, concentrated on 2.65.3: the `reused`
fixture's describe calls predate the one describe door — the CLI rows never pass `--engine`, the tab body states every
field explicitly — so the door's new engine rule, its defaults (left-out voltages, junction, rename, treatment), its new
tab refusals and its one manifest are walked by no row, and the fit door by no test at all. 2.65.4 will break one test
that pins describe's 2.65.3 writes (5051) and possibly one note (4648). The other recurring pattern is reaching a state
by hand where the road or a click reaches it: two tests move the shared run's kept digest away, and the four browser
tests set the sidebar, the session note or the inspector's mount by JavaScript instead of the clicks a person makes.
