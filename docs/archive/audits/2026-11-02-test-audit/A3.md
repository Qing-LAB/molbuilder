## 3. Patterns

The handcrafting entered at the tier-1 boundary. The basic suite may not run an engine, so a state only a
launch makes is planted with the product's own writer instead (`_road_launched` writes `run.json`; a launch
would hit the tripwire), and a description is typed or edited directly (`task.json`, `job-request.json`)
rather than through Save. Writing it "through the product's writer" read as legitimate. The same move,
repeated for the machine, created the dangerous helpers: `conftest.write_machine_record` and `support/road.py`
write `environment.json`, named records and `molbuilder.json` through `config_dir()` at call time, relying
entirely on pytest's function-scoped autouse to point that somewhere temporary. No writer checks for a real root,
and they all carry one fabricated shape (`preamble "true"`, no machine, no probe date), which is the record that
