### ROGUE — reaches outside its sandbox (worst first)

1. **`tests/test_envs_enters_the_env_through_the_manager.py:380, 383, 391`** — `prefix = "/scratch/me/molbuilder-pySCF"` is handed to `install.run_step` for a PACKAGES step and a REMOVE step. `run_step` calls `builds.env_for_step(prefix, make_dirs=True)` (`install.py:266`), which calls `os.makedirs("/scratch/me/molbuilder-pySCF/var/tmp")` and `.../var/cache/pip` (`builds.py:693-701`). 3. **The incident's helper, reached by `tests/test_machine_record.py:29-30`** (`run_road_case`). Nothing in the chain refuses a real root:
   - `conftest.write_machine_record` (`conftest.py:1173-1212`) writes the modest record to `machine_scope_path()`. That record has `preamble: "true"`, no machine and no probe date, which is exactly the record the user found.

## 3. How the handcrafting crept in

1. **Factories make fake runs cheap.** `tests/spectra/_helpers._make_results` and `test_blueprint._make_minimal_results` build whole result objects, and other modules import them, so a "run" costs one line and looks legitimate.

2. **The real writer launders planted state.** Writing through molbuilder's own writer (`write_launch`, `queue_job`, `write_environment`, `dump_spectra_json`, `D.write_description`) is offered as the justification ("written by the product's own writers"). The result is still a record of a run that never happened.

3. **Cross-test imports spread one file's shortcut.** `test_engine_offset_reaches_every_deck._prep` (a hand-written `environment.json` with `preamble: "true"`), `_extract_fn_source`, `_assigned`, and `support/junction.py` → `test_transport_compose` all carry one file's shortcut into others unseen.

4. **External tools are faked by default.** Monkeypatching `subprocess.run`/`run_streaming` is the default way to test a wrapper around an external tool, which is exactly the "answer swapped in-process" that § 0 forbids.

5. **The JS files test the client against an imagined server.** Each `*_js.py` hand-rolls node plus a fetch stub that types the server's reply. Two shipped bugs (info-bridge's flat key, page.js's six invented names) lived in that gap. Per-panel and per-function copies were never collapsed after the code was unified behind `panelDeps.generate` and `_fetchEnvelope`.

6. **Isolation is a per-file habit and lives only in pytest.** Process-global product state (`_MANAGER_RUN_UNUSABLE`, `_RECORDED_MANAGER_RUN`, the progress plugin's `_STATE`) is reset by one file and not by its sibling. Absolute fake paths (`/scratch/me/...`) are treated as inert strings even when product code acts on them. The helper chain `conftest.write_machine_record` → `support.road` writes, and for `"unprobed"` deletes, through `machine_scope_path()` without ever refusing a real root. Its safety exists only inside pytest's function-scoped autouse, which is how a hand run reached the real config.
