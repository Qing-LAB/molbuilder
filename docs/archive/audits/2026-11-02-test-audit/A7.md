## 3. How the handcrafting crept in

1. **Writing a record by hand looks like the sanctioned way.** `conftest.write_machine_record` builds a record with no probe behind it (`preamble: "true"`, no machine, no date) and writes it wherever `machine_scope_path()` resolves, with no refusal of a real root. So a test that needs a machine, a named target, a calculation snapshot or a hand-over writes the JSON itself instead of running the maker (`jobset probe --write`, the hand-over route, prep's first-prep snapshot). `test_task_setup_tab` types `environment.json` raw; `test_engine_offset` plants the snapshot prep would take.

2. **The writer is real but the content is invented.** `dump_spectra_json`, `write_environment` and `StructureCodec.write` produce the right format, so the file feels road-made. What is inside claims something that never happened: an SCF energy, a probe date, a vibration run.

3. **Older-release files survived the 2026-10-16 ruling.** The v12/v13 sidecar rows, the "older schema" template and the committed schema-13 Au-BDT-Au sidecar are edits of current output into an older shape.

4. **Decks are rendered directly instead of through prep.** `spec_for`→`render_deck` is cheaper than `describe → prep`, so whole transport files test the renderer, not what prep writes.

5. **Served-page ids are a second, hand-kept copy.** The id lists copy the JS's selectors (`REQUIRED_IDS`), so the page text is pinned against another file through that copy.

6. **JS harnesses drift from the server.** Hand-rolled stubs type the server's replies, cut function source out of a file, or regex the exports away. The reply shapes can drift from the routes.

7. **Isolation is assumed, not built.**
   - A module-scoped fixture calls product code before the per-test isolation exists.
   - Subprocesses run from the repository root.
   - `validate()`'s default `projects_root()` reads the developer's pseudopotential library, and the conftest carve-out lets that pass without notice.
