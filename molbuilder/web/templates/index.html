    3. Generate input

    Defaults reproduce a standard small-system DFT setup (DZP basis, 300 Ry mesh, GGA-PBE, SCF-only or CG relaxation). Tweak whatever you need; everything not shown stays at the SIESTA default.

    Run directory & restart

    The Job name field in the form below drives the basename for every output file: <name>.fdf, <name>.molwatch.log, <name>.out (recommended redirect target), and the .XV / .DM / .CG restart files. Keep identical across staged runs.

    Important: SIESTA restart-from-folder behavior
    With the default continuation flags (MD.UseSaveXV / DM.UseSaveDM / MD.UseSaveCG all on), SIESTA silently overrides the AtomicCoordinatesAndAtomicSpecies block in the generated FDF when a <name>.XV file exists in the run directory — the saved coordinates win, not the FDF's. Same for .DM (density-matrix warm-start) and .CG (CG state resume). This is what makes staged relaxation work: stage 2's FDF can carry stage 1's input coords and SIESTA still picks up stage 1's converged geometry.

    For a clean fresh start, either run in an empty directory, delete <name>.XV / .DM / .CG first, or change SystemLabel. SIESTA falls back to the FDF coordinates silently when none of those files exist.
