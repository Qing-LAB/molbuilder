{#- molbuilder Projects sidebar -- always-visible left panel. Included by every main tab template (build, modify, watch, spectra) after _app_header.html and before
. CSS in lib/projects- sidebar.css fixes the panel to the left edge under the app-tabs header; CSS body { padding-left: var(--sidebar-w); } shifts the main content right by the sidebar's width. The sidebar's behaviour comes from lib/projects-sidebar.js: * lists projects/<...> entries one level at a time * breadcrumb at the top with clickable parent links * clicking a directory drills in; clicking a file selects it * selection is written to sessionStorage.molbuilder.current_{dir,file} so subscriber tabs (their projects-selection.js shim) react live via the storage / molbuilder.selection events The toggle button in the header collapses the sidebar to a thin strip when the user wants the main content to take the full width. -#}
