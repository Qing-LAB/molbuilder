{#- molbuilder shared header + app-tabs nav. Included by every main tab template. Each caller sets active_tab to one of the canonical key values defined in ``molbuilder.web.tabs.TABS`` (currently: "molbuilder", "structure-optimization", "spectrum-calculation", "transport-calculation", "results"). The project-wide tagline lives HERE -- one canonical sentence that describes what molbuilder is, shown on every page (so users reading any tab immediately know what they're looking at). It is NOT page-specific; per-page descriptions belong in the page body, not the banner. Plain-text only: literal Unicode characters (em-dash, middle-dot) instead of HTML entities (``—`` / ``·``), because Jinja autoescape (pinned ON in Round 5 for XSS hygiene) writes ``&`` as ``&`` and the entities then render as visible "—" gibberish. Styling lives in static/lib/tabs.css. The order + labels are the single source of truth in ``molbuilder/web/tabs.py``; this partial iterates over the ``tabs`` template variable injected by the app's context processor, so reordering or renaming a tab is a one-place change. Tab labels and routes are documented in docs/tabs/architecture.md. The bare ``/`` 302-redirects to whichever tab is first in TABS so the host root always lands on the canonical landing tab without hard-coding the path here. Watch was retired 2026-05-19 -- the /watch route + template + bootstrap are gone; trajectory inspection is /results-only via the registry's trajectory adapter. Picking a ``.molwatch.log``, ``.out``, or other ``TrajectoryParser``-recognised file in the sidebar on /results auto-mounts the inspector. -#}
