    4. Describe the composite

    Transport is an assembly built from ONE cited result: pick the relaxed junction's finished attempt, and prep derives everything else — the sorted copy, both electrode cells, the seed, the NEGF device and the TBtrans transmission — as five stages of one calculation. The electronic contract (basis, XC, mesh) comes from the cited attempt's own .fdf; the fields above travel only where they are transport's own (transmission window, contour — changed values ride as stage overrides).

    After sending: the five-stage road
    1. Open Task setup on that folder, review, and save — task.json is the whole floor 2 (no template: the contract arrives from the citation at prep).
    2. prep run seed → launch; then electrode_L, electrode_R; then device (a bias scan launches as ONE chain job walking the points, each warm-started from the previous point's .TSDE); then transmission.
    3. summarize run — writes <label>.transport.json (T(E) per bias, G(E_F), the I–V table from TBtrans's own integral).
