Transport calculation

This tab will generate TranSIESTA (NEGF) and PySCF-NEGF input scripts for a relaxed device geometry with electrode and bridge regions tagged in the Structure tab's .molstruct.json sidecar.

Status: placeholder. Form skeleton and backend implementations are not yet wired; see docs/tabs/architecture.md and docs/roadmap.md for the planned scope.

Foundations already in place (no UI yet):

  • molbuilder/transport/ — engine abstraction + TransportConfig + TransportResults.
  • Region labeling on the Structure tab — the .molstruct.json sidecar carries regions assigned via the selection panel.
  • Both transport engines (planned: TranSIESTA and PySCF-NEGF) will consume the same relaxed geometry + sidecar; their render_script methods will emit engine-specific inputs from the same config + structure pair.
