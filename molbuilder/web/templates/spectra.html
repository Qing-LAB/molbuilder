Generate

Outputs: frequencies in cm⁻¹, Raman activities in Å⁴ / amu (Placzek 45 a² + 7 γ²), MO energies in Hartree. Two normal-mode forms are stored per mode: eigenvector_canonical (mass-weighted, Σ m·|L|² = 1; for post-hoc Raman / IR re-computation) and eigenvector_display (max(|L|) = 1; for 3D animation).

Resume from a prior run (optional)

Point at an existing <job>.spectra.json to enable the top-N / threshold mode selectors (they need Raman activities that the prior run computed) and to skip already-completed modes when resuming. Leave empty for a fresh job.
