Build DNA from a 1-letter sequence (ACGT) in B / A / Z helix form. Picks the best installed backend (3DNA preferred, AmberTools fallback).
Canonical duplex: prefix with ds, — e.g. ds,ATGCATGC — for a Watson–Crick duplex; the complementary strand is generated automatically (B / A / Z helix — Z needs an alternating poly-d(GC) sequence).
Explicit / mismatched duplex: give the two strands comma-separated — e.g. ATGCATGC,GCATGCAT — both 5'→3', paired antiparallel and equal length. A non-complementary base pairs as a mismatch (a B-form starting model — relax before use). B-form only. (Requires 3DNA. Read 5'→3'; write 3'-…-5' to reverse a strand.)

Build single-stranded RNA from a 1-letter sequence (ACGU) in A / B / Z helix form. A-form is the canonical RNA helix; the backend picks the best installed builder (3DNA preferred, AmberTools fallback).

Build a peptide from a one-letter amino-acid sequence (e.g. ACDEF). Generates an extended conformation via AmberTools' tleap.
