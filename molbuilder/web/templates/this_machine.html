What the target machine needs, if it is not this one

A prepared bundle is copied to the machine that runs it, and the monitor beside the job reads its channels there. Nothing in the run script carries an address or a key — it assumes you have put them in place. What it looks for:

<config dir>/notify
the channels file, mode 0600, in the same shape as the one on this page. A channel a description ticks must exist there by the same name, or nothing is sent to it — the monitor log says which.
<config dir> is
$MOLBUILDER_CONFIG_DIR exactly as given; else $XDG_CONFIG_HOME/molbuilder; else ~/.config/molbuilder. Resolved on that machine, so it need not match this one's.

Running molbuilder there and using this page is the simplest way to put it in place; copying the file across works too.
