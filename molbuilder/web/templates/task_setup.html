      Tell me how it is going

      A long run does not need watching. Tick what is worth a message and it is written into this calculation's job request. Nothing ticked is no reports at all; once anything is, the run's start and end report too.

      Send it to

      Channels are named once on the This machine tab; this picks which of them this calculation uses. Only the names travel — no address and no key reaches this page, or the file it writes.
