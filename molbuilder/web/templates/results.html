Open a directory in the Projects sidebar on the left, then click Reload from current project dir. Browsing the sidebar on its own leaves this panel where it is, so you can look around without losing what you are reading. The Result file dropdown above then lists what that directory holds; selecting one mounts the matching viewer.

  • *.molwatch.log *.out — trajectory + SCF history + force vectors
  • *.spectra.json — a vibration: its modes, their 3D animation, and the infrared / Raman spectrum where the run computed strengths
  • *.xyz *.pdb — structure preview (3D viewer + atom info)
  • job-set.json — a benchmark sweep: every trial compared, what each asked for beside what it ran, and the verdict
  • *.transport.json — a transport calculation: the I–V table, G(EF) and what is not drawn
  • *.fc-sweep.json — a SIESTA vibration's displacement sweep: each force-constant stage and every mode compared across them

For source files (*.fdf *.py *.log *.json *.txt *.md), use the View button next to each file in the Projects sidebar — it opens a text viewer scoped to that file. Results / inspector flows on this tab are reserved for files that carry structured data the engines produce.
