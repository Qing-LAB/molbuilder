Pick a file to inspect

Navigate the Projects sidebar on the left to a directory that contains result files. The Result file dropdown above lists every result-class file in the current directory; selecting one mounts the matching inspector. If the dropdown is hidden, the directory has no result files yet.

  • *.molwatch.log *.out — trajectory + SCF history + force vectors
  • *.spectra.json — vibrational spectra (Raman / IR) + 3D mode animation
  • *.xyz *.pdb — structure preview (3D viewer + atom info)

For source files (*.fdf *.py *.log *.json *.txt *.md), use the View button next to each file in the Projects sidebar — it opens a text viewer scoped to that file. Results / inspector flows on this tab are reserved for files that carry structured data the engines produce.
