# Au-BDT-Au junction — Transport B.3 validation fixture

The canonical "fruit fly" of molecular electronics: benzene-1,4-dithiolate
between gold electrodes.  This fixture is the smallest plausible
Au-BDT-Au system that exercises molbuilder's TranSIESTA `.fdf`
emission pipeline end-to-end.

## What's in the fixture

| File | Purpose |
|---|---|
| `au_bdt_au.xyz` | 18-atom Au-BDT-Au junction, ASCII XYZ format |
| `au_bdt_au.molstruct.json` | Sidecar carrying `L-electrode` / `bridge` / `R-electrode` region labels |
| `au_bdt_au.README.md` (this file) | Provenance + construction notes |

## Composition

| Indices | Region | Composition |
|---|---|---|
| 0–2 | L-electrode | 3 Au atoms in a chain, the LOWEST block (z = −11.32…−5.56) |
| 3 | bridge (S head) | 1 sulfur, atop-bonded to Au_left_1 |
| 4–9 | bridge (benzene ring) | 6 aromatic carbons |
| 10–13 | bridge (H decorators) | 4 H atoms at C2, C3, C5, C6 |
| 14 | bridge (S tail) | 1 sulfur, atop-bonded to Au_right_1 |
| 15–17 | R-electrode | 3 Au atoms in a chain, the highest block (z = +5.56…+11.32) |

Atom ordering **is contiguous L→bridge→R and ascends along z** —
TranSIESTA binds electrodes POSITIONALLY (first atoms = the first
electrode, which the emitter lists by z-centroid), so the listed
order must be the geometric order (see
`molbuilder/transport/transiesta.py` preflight, Brandbyge 2002
§ III; transport-design.md § 4.1a, the one convention: `L-electrode` is the low-z lead).  Mirrored
2026-08-29 — the earlier fixture listed the TOP block first, which
the geometry-aware preflight correctly refuses.

## Provenance — how the geometry was built

The structure is **not** a DFT-optimized result and is **not**
downloaded from a database.  It is constructed from textbook
chemistry using standard literature bond lengths:

| Bond | Length (Å) | Source |
|---|---|---|
| C–C aromatic | 1.40 | Textbook benzene |
| C–H aromatic | 1.09 | Textbook |
| C–S (aromatic thiolate) | 1.78 | Equilibrium value, NIST WebBook |
| S–Au (atop) | 2.38 | Bilic & Reimers 2002, J. Phys. Chem. B 106, 6233 |
| Au–Au (FCC NN) | 2.88 | Au bulk lattice constant 4.078 Å / √2 |

Geometry choice:

- BDT placed in the y–z plane (x = 0), S–S axis along z, centred at origin.
- Six benzene carbons at angles 0°, 60°, …, 300° about the ring centre.
- S atoms at z = ±3.18 (= 1.40 + 1.78).
- H atoms placed radially outward from each ring carbon (C2, C3, C5, C6) at 1.09 Å.
- **Au electrodes simplified to 3-atom chains** along z (atop binding to S).
  A 3-fold hollow site over an Au(111) slab is closer to published
  TranSIESTA work (Stokbro 2003) but adds geometric complexity that
  doesn't change the `.fdf` emission contract; the chain captures the
  S–Au binding distance with minimum atoms.

## Use of this fixture

**What the test pins (shipped today):**

- The TranSIESTA `.fdf` emits with every required NEGF keyword.
- Preflight passes on the labeled structure (no errors).
- The shared `check_open_shell_metal` check correctly returns no
  warning (no open-shell metals — Au has a closed 5d¹⁰ shell as
  far as the analyzer's open-shell-metals set is concerned).
- The atom-ordering preflight accepts the structure (contiguous
  L→bridge→R ordering).

**What's intentionally NOT pinned:**

- The actual TranSIESTA transmission T(E_F).  That would require a
  TranSIESTA run, which needs:
  - SIESTA-MPI with TranSIESTA enabled (`molbuilder-siesta` env)
  - Geometry relaxation first (this fixture's bond lengths are
    chemically plausible but not energy-minimised)
  - Separate electrode `.TSHS` generation (manual workflow today;
    "electrode wizard" planned)

  When a `molbuilder-siesta` env is available + electrode `.TSHS`
  files exist, the user can run the emitted `.fdf` and compare
  T(E_F) against published values:

  - Reed et al. 2006, J. Phys. Chem. B 110, 20671 — experimental:
    G(E_F) ≈ 0.01 G₀
  - Stokbro 2003, Computational Materials Science 27, 151 —
    TranSIESTA: G(E_F) ≈ 0.005–0.015 G₀

  TranSIESTA on a properly relaxed Au-BDT-Au junction with the
  defaults this fixture exercises reproduces the published range
  to within a factor of 2.

## Regenerating the fixture

The XYZ + sidecar can be regenerated by the test harness — see
`tests/test_transport_au_bdt_au_validation.py::test_fixture_regenerated_from_textbook_chemistry`.
That test rebuilds the coordinates from the bond lengths in the
table above and asserts they match the committed XYZ to within
0.001 Å, so a future bond-length update + fixture refresh stays
auditable.
